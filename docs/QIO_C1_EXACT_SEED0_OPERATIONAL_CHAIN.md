# qIO C1 exact seed-0 operational chain

Status: frozen static chain; no job, reservation, process, Space, or control-plane mutation was performed while building it.

## Bound scientific core

The route consumes the existing 31-file source manifest, execution contract, continuation runner, independent NumPy auditor, and terminal return verifier without changing them. The deterministic source archive contains the 31 declared payload files plus the source manifest and execution contract. The job wrapper verifies every hash before creating or resuming its persistent work directory.

The route is C1-only. It resumes seed 0 from exact update 100 to update 1,000,000, then performs the frozen 50-episode policy evaluation and 32,768-tuple held-out twin-survival audit. It is not C3, not a Table-1 benchmark, and cannot guarantee a score change.

## Admission and persistence

`hf_jobs/launch_qio_c1_exact_seed0.py` is read-only unless `--submit` and both exact approval variables are supplied. At both the initial and final submit boundary it rejects:

- protected PID 41861 or any matching qIO command, without signaling it;
- any account-wide RUNNING/SCHEDULING T4;
- an absent or malformed central reservation `pending-qio-c1-exact-seed0-full-v1`;
- any COMPLETED/RUNNING/SCHEDULING job with the exact four route labels;
- a Space parent other than `757e63d6377d6a3789657d75e354306c95d6e43f`;
- source archive, contract, component, checkpoint, protocol, or data drift.

The only submit command uses `t4-small`, a 48-hour timeout, exact route labels plus a unique submission token, a read-only frozen input mount, and the persistent `qIOcJSCGn2-artifacts` bucket. Scientific state lives once under `hf-jobs/qio-c1-exact-seed0-full-v1/state/results/`; attempt receipts live under `attempts/<submission-token>/`. A timeout retry therefore receives a new reservation and submission identity while resuming the shared immutable-checkpoint state. An already completed route is never rerun.

## Terminal import

`repro/hf/import_qio_c1_exact_seed0.py` accepts only one terminal COMPLETED exact-label job, rejects route duplicates and wrong submission identity, synchronizes its persistent bucket prefix, rejects partial returns, and invokes the existing verifier for independent local recomputation. The verifier imports into a completion-hash-named local directory. No returned result is promoted into the public evidence tree automatically.

## Existing-Space-only repair

`repro/hf/prepare_qio_c1_exact_seed0_space_repair.py` prepares an overlay against the pinned existing Space parent. It uploads no C2 file and appends the exact-scale result to the three C1-summary pages while retaining their previous contents. It reports negative or inconclusive evidence as returned; it never assumes a score increase.

Publication is disabled by default. It requires `--publish`, an explicit override of the frozen contract's publication block, exact approval environment variables, and a fresh parent-SHA check. Post-upload readback compares every non-allowlisted parent file and the C2 page byte-for-byte.

## Remaining live gates

The chain is statically complete but not currently authorized or operationally ready. A future root reservation is necessary, but not sufficient: PID 41861 and matching qIO processes must be absent naturally, all campaign T4 work must be terminal, the exact route must have no completed/running/scheduling duplicate, and the pinned Space parent must still match. None of those blockers may be cleared by killing or mutating existing work.
